# MSW 글로벌 개발 콘테스트 Tracker

MapleStory Worlds **글로벌 개발 콘테스트 참가 월드**를 주기적으로 수집해 SQLite에 스냅샷으로 저장하고, Streamlit 대시보드에서 순위/증가량/신작/장르별 현황을 보는 로컬 도구입니다.

## 제공 기능

- 글로벌 개발 콘테스트 카테고리의 월드 URL 자동 발견
- 게임명 / 월드 ID / 장르 / 출시일 / 최근 업데이트 / 최대 인원 / 플랫폼
- 총 플레이어 / 즐겨찾기 / 좋아요 수 / 좋아요율 / 댓글 수(페이지에 숫자가 노출되는 경우)
- 1시간 / 24시간 / 7일 플레이 증가량
- 전체 랭킹, 급상승 TOP, 장르 분석
- 월드별 시계열 그래프
- 현재 표 CSV 다운로드 (Excel에서 바로 열 수 있음)
- 기본 30분 간격 자동 수집

> **주의:** 메월드 웹사이트의 공개 화면을 읽는 방식입니다. Nexon이 페이지 구조/라벨을 바꾸면 `collector.py`의 파싱 규칙을 조정해야 할 수 있습니다. 너무 짧은 주기로 요청하지 않도록 기본값은 30분입니다.

## Windows에서 처음 한 번

1. 이 폴더를 원하는 곳에 압축 해제
2. Python 3.11+가 설치되어 있는지 확인
3. `install.bat` 실행
4. 설치가 끝나면 `collect_once.bat`으로 첫 수집 테스트
5. `start_all.bat` 실행

`start_all.bat`은 다음 두 개를 같이 켭니다.

- 30분마다 자동 수집하는 창
- 브라우저에서 보는 대시보드

## 평소 사용

그냥 `start_all.bat` 실행하면 됩니다.

대시보드만 보고 싶으면 `start_dashboard.bat`을 실행합니다.

## 수집 주기 변경

기본은 30분입니다. 명령 프롬프트에서 예를 들어 60분으로 실행하려면:

```bat
set MSW_INTERVAL_MINUTES=60
python collector_loop.py
```

콘테스트 기간 동안 서버에 무리가 가지 않도록 10분 미만의 매우 잦은 수집은 권장하지 않습니다.

## 데이터 파일

모든 기록은 같은 폴더의 `tracker.db`에 저장됩니다. 이 파일 하나에 과거 기록이 계속 쌓입니다. **삭제하면 과거 증가량 기록도 사라집니다.**

## 댓글 수

총 플레이어/즐겨찾기/좋아요는 공개 페이지의 라벨을 기반으로 파싱합니다. 댓글 수는 메월드가 페이지 본문에 숫자를 직접 노출하는 경우만 자동 저장하고, 노출되지 않는 월드는 빈칸으로 둡니다. 추후 댓글용 내부 요청이 안정적으로 확인되면 별도 수집기를 붙일 수 있도록 DB 열은 이미 포함되어 있습니다.

## 수동 테스트

처음에는 5개만, 브라우저를 보이게 테스트할 수도 있습니다.

```bat
python collector.py --show-browser --limit 5 --debug
```
